# Canny Edge Detector

An interactive Computer Vision web application built with Python, OpenCV, and Streamlit. It enables users to upload images and apply the Canny Edge Detection algorithm with real-time parameter tuning.

Live Demo: [Canny Edge Detector Web App](https://canny-edge-detector-alvinjoseph.streamlit.app/)

---

## Features

- **Image Upload**: Supports standard image formats including JPG, JPEG, and PNG.
- **Real-Time Threshold Tuning**: Interactive sliders for adjusting minimum and maximum hysteresis values.
- **Instant Visualization**: Fast computation and rendering of edge maps using OpenCV.
- **Side-by-Side Comparison**: Displays original uploaded images next to processed edge outputs for immediate analysis.

---

## Tech Stack

- **Framework**: Streamlit
- **Computer Vision**: OpenCV (`opencv-python-headless`), NumPy, Pillow
- **Language**: Python 3.8+
- **Deployment**: Streamlit Community Cloud
